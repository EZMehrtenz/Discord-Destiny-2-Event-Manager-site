Contact the project

Email support
d2embot@outlook.com

Operated by EZMehrtenz. Support is handled manually; there is no guaranteed immediate response.

Please contact us from an address you can receive replies at. A server’s private administrator channel can help staff coordinate internally, but this email address is the public route available to every Member.

Help with the bot

Include the command or button you used, what you expected, what happened, and the approximate time with your time zone. A screenshot is helpful if it does not expose other people’s private information. Include the relevant server or ticket ID if you know it.

For channel access, role hierarchy or local moderation decisions, your server owner or administrator is often the best first contact. For an in-game entitlement or account problem, use Bungie’s own support channels.

Never send a bot token, database connection string, password, authentication code or API key. Remove those details from screenshots and logs before sharing.

Request access, correction or deletion

Use the subject Data request — Destiny 2 Event Manager. Tell us:

  • Your Discord user ID and, if useful, your current Discord name.
  • The relevant server or servers, if the request is server-specific.
  • Whether you want access to your information, a correction, deletion, or another privacy review.

We may ask for confirmation that you control the Discord account. Requests are handled manually. You do not need to send identity documents, passwords or authentication codes unsolicited.

Unregistering is not full deletion. /unregister removes the registration in the current server. The reusable Bungie link and historical ticket/event records are kept unless separately removed. Use this contact route for a broader deletion request.

See the Privacy Policy for the data categories and visibility of bot posts.

Report a security issue privately

Use the subject Security report — Destiny 2 Event Manager and describe the issue without exposing credentials or other Members’ information. Please do not publish a working exploit or private data in a public issue or game channel.
